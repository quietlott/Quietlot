/01 How it works

From mandate to settlement

Four steps. You always sign the transaction yourself from your wallet.

  1. 01

    Set a mandate

    Choose the asset pair, quantity, price limit, and expiry. Price limits are not shown publicly.

  2. 02

    Agents find a match

    Agents pair complementary mandates and reject self-matches and expired mandates.

  3. 03

    Bounded negotiation

    Agents exchange offers over a limited number of rounds. Each offer is checked in code against the seller's net floor before a wallet is asked to approve.

  4. 04

    Atomic settlement

    Both parties sign from their own wallets. Tokens move in a single on-chain transaction, or not at all.

/02 Features

Built for trades that should not leak

Price privacy, safe execution, and no third-party custody.

PRIVACY

Private price limits

The seller's minimum and the buyer's maximum are used only by agents during negotiation. They are never published to an order book.

CUSTODY

Non-custodial

Agents hold no private keys. Funds move from your wallet only when you approve a settlement.

CHECKS

Net floor in code

The contract guarantees the seller receives at least the minimum after fees. Offers that break this floor are rejected.

EXECUTION

Atomic settlement

ERC-20 swaps happen in a single transaction. There is no half-completed state.

SAFETY

No self-matching

Mandates from the same address are never paired. Each mandate can be used only once.

CONTROL

Cancel on-chain

Cancel a mandate on-chain at any time before settlement, so it can no longer be executed.

/03 Fees

Pay only when a trade settles

No subscription. Failed negotiations and cancelled orders cost nothing.

Standard · 20 bps

0.20%

Applies to all sellers who do not hold the discount token.

Discount holders · 10 bps

0.10%

Applies when the seller's discount token balance meets the threshold set in the contract.

Ceiling · 50 bps

0.50%

A hard maximum set in the contract. It cannot be raised.

Fees come from the seller's proceeds and are calculated on the gross amount before the fee.

/05 FAQ

Before you try it

Do the agents hold my funds?

No. Agents have no private keys and never custody funds. You sign the mandate and token approvals from your own wallet.

Are the contracts audited?

Not yet. The contract code, tests, and audit scope are public on GitHub, so anyone can review them. No independent auditor has signed off yet, so use only funds you can afford to lose.

What happens if a negotiation fails?

There is no fee. Fees apply only when a settlement succeeds.

Can I cancel a mandate?

Yes. You can cancel a mandate on-chain before it settles. Once cancelled, it can no longer be executed.

Are fee-on-transfer tokens supported?

No. Use standard ERC-20 tokens only.
